In order to upload the content of the "data" folder one needs to install the plugin:

https://github.com/earlephilhower/arduino-littlefs-upload/releases

In order to upload use ctrl+shift+p and search for littleFS and click it.
The data folder needs to be in the arduino project.

more info about the littleFS:
https://makesmart.net/blog/read/dateien-auf-dem-esp8266-speichern-und-lesen-das-spiffs-dateisystem
